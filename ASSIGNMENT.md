# AI Decision Flow (BE-09)

Create a React or Next.js app with React Flow, Inngest, OpenAI SDK and shadcn. Allow adding, connecting and editing prompt nodes, label YES and NO edges and keep graph state locally. Execute each node as an Inngest step using an LLM that returns YES or NO; traverse the appropriate edge and track execution order. Add at least three usability features from the brief (execution state, logs, save/load, import/export, styling, errors, retries, animated edges, history). Configure environment variables and document setup.
